# `lpt go-native`: migrate non-native installs to native packages

**Date:** 2026-09-11
**Status:** Implemented (`lib/go_native.rs`, `tests/go_native.rs`)
**Context:** Snap, flatpak, nix, and `curl | sh` installs are software
`lpt` could own (updates, checksums, rollback) but currently doesn't.
`go-native` detects them, maps each to a native package, and migrates —
plan by default, apply with `--yes`.

## Design

- **Two-stage plan/apply.** The command prints the migration plan by
  default and only mutates with `--yes`. Same trust model as
  `--dry-run` elsewhere in lpt.
- **Curated mapping table.** A compiled-in `MAPPINGS` array (45 rows:
  snap name, flatpak id fragment, nix attr, orphan binary, installer-URL
  pattern → native package). Compiled in rather than a data file so the
  table ships with the binary and stays testable; community additions are
  PRs against one obvious array.
- **Exclusion list.** `EXCLUDED_SNAPS` (`core*`, `mesa-*`, `snapd`,
  theme packs): runtimes that will never have a native equivalent and
  must not be proposed.
- **Unmapped report.** A `missingnative` section lists findings with no
  mapping: reported, never silently dropped, never acted on.

## Deliberate differences from managed-source migration

- **The `curl | sh` source has no package database,** so detection is
  heuristic: orphan binaries unclaimed by `dpkg -S`/`rpm -qf`/`pacman
  -Qo`, with shell-history greps attributing the installer URL.
  Best-effort by design.
- **No auto-delete for orphans.** A `curl | sh` orphan has no manifest,
  so `go-native` prints manual `rm` cleanup instead of executing it.
- **Apply is deb-host-only.** Removal/install reuses the existing
  `lpt install` backend (dpkg). On rpm/Arch hosts the plan doubles as a
  shopping list until the install backend grows formats. This is stated
  in the output, not hidden.
- **Manager removal is opt-in + confirming** (`--remove-manager`), and
  only offered when re-detection shows nothing unmigrated remains for
  that manager.

## Defaults chosen (were open questions)

- Removal default: source removed after successful native install,
  `--keep-source` to keep both.
- `curl | sh` scan defaults **on** (`--skip-sh` to skip) — the full
  picture is the point of the command.
- Mapping table compiled in (see above), with `lpt search` as the manual
  fallback for unmapped packages.
